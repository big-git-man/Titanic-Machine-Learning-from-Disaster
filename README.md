# Titanic - Machine Learning from Disaster

Kaggle Titanic competition project.

## Competition

**Competition:** Titanic - Machine Learning from Disaster  
**Target:** Survived  
**Metric:** Accuracy  
**Training rows:** 891  
**Test rows:** 418

## Project Goal

Build and improve machine learning models that predict whether a Titanic passenger survived based on passenger information such as class, sex, age, family relationships, ticket, fare, cabin, and embarkation port.

## Planned Workflow

1. Establish a baseline
2. Test classical machine learning models
3. Compare validation accuracy
4. Engineer useful passenger and family features
5. Tune promising models
6. Evaluate using cross-validation
7. Generate Kaggle submissions
8. Track improvements over time

## Planned Models

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- CatBoost

## Planned Feature Engineering

- Family size
- Is alone
- Passenger title
- Cabin deck
- Ticket group size
- Fare per person
- Useful feature interactions
